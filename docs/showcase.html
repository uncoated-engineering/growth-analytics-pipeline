architecture

A medallion lakehouse with a governed serving layer

Raw JSONL feeds land append-only in bronze; silver conforms them (SCD Type 2 dimensions, subscription-event periodization); gold ships business marts. Every table is its own PySpark module with schema, transformation, and input/output data-quality gates that Airflow runs around each task.

Downstream, a DuckDB engine resolves each table's current Delta snapshot via delta-rs and serves the semantic layer, the CLI, and the chatbot — interactive SQL without a Spark cluster.

the flagship mart

MRR waterfall — consistent by construction

Subscription lifecycle events (started, expanded, contracted, upgraded, cancelled) carry MRR before and after each change, so revenue movements are simple deltas. Starting and ending MRR are a running total of those movements, which makes ending = starting + net_new hold for every month — an identity the test suite asserts.

ai analytics

Ask the lakehouse a question

The chatbot (Claude + tool use) has exactly two tools: governed metric queries and guarded read-only SQL. Every query it runs is shown next to the answer — auditable, not a black box.

Which acquisition channel brings the best customers?
query_metric { metrics: [conversion_rate, signups, acquired_mrr], dimensions: [acquisition_channel] }

Referral is the strongest channel: a 41.3% conversion rate (210 of 509 signups) and $333K in acquired MRR — nearly double the conversion rate of paid social (21.9%) and outbound (21.8%).

Content marketing (35.9%) and organic search (34.0%) follow; organic is the largest volume source with 1,192 signups. Source: gold_channel_performance.

engineering practice

Built like production software

CI on every push

GitHub Actions: ruff, black, mypy, and the full Spark + Airflow + semantic test suite with Java and uv caching.

Tests mirror the source tree

tests/spark/jobs/silver/test_user_dim.py tests spark/jobs/silver/user_dim/ — finding a test is mechanical.

Quality gates in the DAGs

Every table runs assert_input_quality → process → assert_output_quality; schema and row-count checks fail loudly.

Data-aware scheduling

Silver and gold DAGs are triggered by Airflow Datasets — by upstream data landing, not by the clock.

Decisions written down

Seven ADRs cover every major choice, from medallion-on-Delta to the chatbot's safety posture.

Quickstart

# build the lakehouse
$ make setup && make generate-data && make pipeline

# query governed metrics from the terminal
$ uv run python -m semantic.cli query conversion_rate -d acquisition_channel

# chat with the data (needs ANTHROPIC_API_KEY)
$ make chatbot
